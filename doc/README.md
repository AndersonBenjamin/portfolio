## Convenções

- Documentos curtos e objetivos. Detalhe só o que já foi decidido.
- Itens ainda não decididos ficam na seção **Em aberto** de cada documento.
- Ao tomar uma decisão relevante: atualize o documento do assunto e adicione uma entrada em [10-decisoes.md](10-decisoes.md).
- Novos assuntos ganham um novo arquivo numerado.
