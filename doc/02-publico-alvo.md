# Público-alvo

| Público | O que procura | Prioridade |
| --- | --- | --- |
| Recrutadores | Visão rápida de perfil, experiência, contato | Alta |
| Empresas de tecnologia | Evidência de competência técnica, projetos reais | Alta |
| Desenvolvedores | Conteúdo técnico, código, detalhes de implementação | Média |
| Interessados em geral | Projetos e vídeos | Baixa |

## Implicações

- Informações essenciais (quem sou, stack, contato) devem estar acessíveis sem esforço.
- O inglês é o idioma principal para o público internacional.
- Detalhes técnicos existem, mas não podem atrapalhar a leitura rápida de um recrutador.
- Tom: profissional, mas não excessivamente corporativo.
