# Projetos

Tipos: aplicativos, jogos, websites, experimentos e projetos pessoais.

## Informações de um projeto

| Campo | Obrigatório | Observação |
| --- | --- | --- |
| Nome | Sim | |
| Descrição curta | Sim | Usada em listagens |
| Problema / objetivo | Sim | Por que o projeto existe |
| Tecnologias | Sim | Lista de tecnologias usadas |
| Status | Sim | Ex.: em desenvolvimento, concluído, experimento |
| Imagens / screenshots | Não | Ao menos uma imagem é recomendada |
| Link de demonstração | Não | |
| Link do GitHub | Não | Quando o código for público |
| Detalhes técnicos | Não | Decisões, arquitetura, desafios |
| Conteúdos relacionados | Não | Referências a itens de [06-conteudo.md](06-conteudo.md) |

Textos (descrição, problema, detalhes) precisam existir em inglês e português (ver [07-idiomas.md](07-idiomas.md)).

## Relação com conteúdos

Um projeto pode originar conteúdos técnicos, por exemplo:

- Como configurei o Nginx.
- Como implementei determinada funcionalidade.
- Como resolvi um problema de performance.

A relação deve ser navegável nos dois sentidos: do projeto para o conteúdo e do conteúdo para o projeto.
