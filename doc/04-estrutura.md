# Estrutura

Direção inicial das seções. Não é definitiva.

| Seção | Propósito |
| --- | --- |
| Home | Apresentação rápida: quem sou, o que faço, destaques de projetos e conteúdos, chamada para contato |
| Projetos | Lista de projetos com acesso ao detalhe de cada um |
| Conteúdos / Vídeos | Lista de conteúdos técnicos, filtráveis por tecnologia |
| Experiência | Trajetória profissional |
| Sobre mim | Apresentação pessoal, tecnologias, interesses |
| Contato | Formas de contato (e-mail, LinkedIn, GitHub) |

## Diretrizes

- Navegação simples, com poucos níveis.
- Seções devem poder ser adicionadas, removidas ou reordenadas sem reestruturar o site.
- Projetos e conteúdos devem poder referenciar uns aos outros.
