# Conteúdo técnico

Seção dedicada a conteúdos técnicos, principalmente vídeos curtos em inglês.

## Propósito

- Demonstrar conhecimento técnico.
- Praticar comunicação técnica em inglês para entrevistas internacionais.

## Formato

- Conteúdos **independentes e curtos**, não um curso completo.
- Explicar assuntos que já domino.
- Idioma principal dos vídeos: inglês.

## Temas iniciais

Git, Nginx, React, React Native, Node.js, Docker, Linux, APIs, JavaScript / TypeScript, arquitetura.

## Informações de um conteúdo

| Campo | Obrigatório | Observação |
| --- | --- | --- |
| Título | Sim | |
| Descrição | Sim | |
| Tecnologias / tags | Sim | Permite filtrar por tema |
| Data de publicação | Sim | |

| Duração | Não | |
| Projetos relacionados | Não | Referências a itens de [05-projetos.md](05-projetos.md) |
